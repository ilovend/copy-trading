# 币安跟单工具 v1.3.0

把币安「跟单交易」的成交事件实时接到本地，按你自己的比例在**执行账户**里复制：
**监控 / 复制 / 推送 / 自动跟单**，带一个桌面控制台。

> 纯本地运行，密钥只存在你自己的机器上。

---

## 功能

| 模块 | 说明 | 状态 |
|---|---|---|
| **仓位监控** | WebSocket 实时接收全部跟单组合的成交（实测约 100ms），推 Telegram | ✅ |
| **仓位复制** | 按比例 / 每笔固定金额计算执行账户该下多少，含风控与滑点保护 | ✅ 影子 / 干跑 / 实盘 |
| **仓位推送** | Telegram 已接；QQ / 微信 / 钉钉 / Webhook 预留 | ✅ |
| **自动跟单** | 监控收藏带单员名额，出现空位自动加入 | ✅ |
| **自研策略** | 放量急拉 + 高位上影线做空，止盈止损/超时不隔夜 | ✅ 影子 / 干跑 / 实盘 |

复制的三种运行模式：

| 模式 | 行为 |
|---|---|
| 影子 | 只计算、只记录，不碰交易所 |
| 干跑 | 打印完整订单参数，**不发送** |
| 实盘 | 真实下单（IOC 限价 + 双向持仓自适应） |

## 快速开始

```bat
python -m pip install -r requirements.txt
copy .env.example .env
python gui\启动.bat
```

首次使用三步：

1. **仓位监控** 页点「更新登录态」，按弹窗提示从浏览器复制 cURL
2. **仓位推送** 页填 Bot Token / Chat ID → 测试发送 → 保存
3. 列表里点「监控 / 复制」勾选 → 点「启动」

实盘还需要：**仓位复制 → 执行账户** 填 API Key / Secret（只存 `.env`），
点「测试连接」确认权益与持仓模式。

> 开发者/接手者先读 [docs/HANDOFF.md](docs/HANDOFF.md)。

## 关键设计

**信号源是「你自己的跟单账户」。**
监听的是官方跟单镜像到你账户的成交，不是带单员的原始仓位。
不需要带单员授权；代价是它只能当探针，要自定义比例必须另开执行账户。

**WebSocket 走 `/private/stream`。**
币安已改版：旧路径 `/ws/<listenKey>` 能握手但不下发数据；
正确做法是连 `/private/stream` 后发 `SUBSCRIBE [listenKey]`，事件还包了一层 `{stream, data}`。

**参数默认只问三件事。**
执行资金、跟单方式、单笔上限；总敞口、单币上限、滑点、杠杆按安全值自动推导。
需要细调时展开「高级设置」。

**主链路与旁路分离。**
算量和下单所需的四个调用（净投入、盘口、持仓、下单）同步执行；
Telegram 推送走有界异步队列，发不出去也不影响开平仓。

## 自研策略：放量急拉 + 上影线反转

独立于跟单模块的另一条链路，GUI 第五页「自研策略」。默认**影子模式**，只记录不下单。

规则（只用已收盘 K 线，五条同时成立）：

1. **放量**：本根量 ≥ 前 60 根量中位数 × `vol_mult`
2. **波动放大**：本根 TR ≥ 前 60 根 TR 中位数 × `tr_mult`
3. **已被急拉**：过去 `pump_lookback` 根最高价涨幅 ≥ `pump_pct`
4. **上影反转**：阴线、实体 ≤ 1/3 振幅、上影 ≥ 45% 振幅、下影 ≤ 30%
5. 振幅本身 ≥ TR 中位数 × `min_range_atr`

命中 → 立刻 IOC 限价做空。之后：

- **加仓**：首笔后 `add_window_s`（默认 120s）内再出信号，最多加 `max_adds`（默认 2）次，
  且新信号价不低于上一笔（做空越往上加越划算）
- **分批止盈**：+0.6% 平当前仓位 50%，+1.2% 再平剩余的一半（累计 75%）
- **追踪止盈**：盈利到 +0.8% 启动，峰值回撤 0.3 个百分点就平掉剩余
- **兜底**：止损 0.5% 整仓、最长持仓 180s、23:55 前强平；实盘 IOC 不成交立刻转市价

```bat
python bot\strategy_run.py            :: 按 gui/strategy_config.json 跑
python bot\strategy_run.py --scan     :: 看当前涨幅榜候选
python bot\strategy_run.py --probe    :: 现在有没有信号（不下单）
python bot\strategy_run.py --replay 500  :: 回放最近 500 根，看信号频率与假想盈亏
```

> ⚠️ 这条规则非常挑形态：实测 25 个币 × 500 根 1m 只有个位数信号，粗估扣掉手续费后**没有明显优势**。
> 先用 `--replay` 按天验证参数，再考虑实盘。

## 安全

- API Key / Telegram token 只存在 `.env`，不进仓库
- `session.json`（网页登录态）等同账号权限，只在本地使用
- API Key 关掉提现权限、绑定 IP 白名单
- 换代理节点会导致 IP 白名单失效（报 `-2015`）

---

## 已知限制

- 没有独立止损、日亏熔断、连续失败熔断（自研策略模块有自己的止损与日亏熔断）
- 模拟台账不持久化，进程重启后清零（实盘查真实持仓，不受影响）
- 信号串行处理，带单员一次开多个币时可能因排队被丢弃（超过 8 秒判过期）
- 子账户杠杆上限 5x，实盘建议用主账户
